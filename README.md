**Databox** is a fast, interactive Business Intelligence (BI) dashboard built to help users understand complex data easily. It features a fully customizable drag-and-drop workspace, an AI assistant for data insights, and real-time filtering that can be easily shared via URL links.

---

## ✨ Key Features

- **Customizable Workspace (Drag & Drop):** Users can easily drag and drop widgets to build their perfect dashboard layout. The layout is automatically saved so it looks the exact same the next time they log in.
- **AI Insights Assistant:** A built-in AI chat assistant that helps users understand data trends and summarizes complex information in real-time.
- **Shareable Links:** Instead of using heavy state managers, all filters (like dates and categories) are saved directly in the URL. This means you can copy the link, send it to a teammate, and they will see the exact same filtered data.
- **Lightning Fast Performance:** Built with Vite and React 18 to make sure animations, charts, and data loading are incredibly smooth with zero lag.

---

## 🛠️ Tech Stack

### Frontend
- **React 18 & Vite:** For a blazing fast development and user experience.
- **TypeScript:** Ensures clean, reliable, and bug-free code.
- **Tailwind CSS:** For beautiful, responsive, and modern styling.
- **Recharts:** For rendering interactive and smooth data visualizations (SVG charts).
- **@dnd-kit:** Powers the advanced drag-and-drop functionality for the widgets.

## 🚀 Quick Start

To run this project locally on your machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/shreygupta15/Databox.git
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:8080` (or the port specified in your terminal).
